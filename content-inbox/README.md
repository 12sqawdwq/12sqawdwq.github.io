# Writing inbox

These files are editorial stubs and are deliberately excluded from the generated site, type/topic archives, related-writing links, and RSS.

A stub may move to `content/writing/` only after:

1. project-specific mechanisms are checked against the current public repository;
2. technical semantics are checked against primary documentation where needed;
3. private infrastructure, medical, patent, account, and unpublished-result details are removed;
4. `status`, date, topics, project, and claim strength match the public evidence;
5. the normal build and link checks pass.

Do not add private Notion URLs or copy private workspace content into this directory.
