Projects

Repositories, prototypes, research code, and small experiments. Each page links back to writing associated through frontmatter.

Robotics and embodied AI

  • FlyHeadactive project

    A testbed where a GPU-simulated whole-brain fruit-fly connectome (FlyWire, 138,639 neurons, 15.09M connections) drives a real wheel-legged robot. I built the platform around the upstream LIF model, including sensor encoders, the neuron decoder, safety layer, LiDAR SLAM navigation and web console.

Engineering and scientific computing

  • Sky Atlaslive site

    A live, bilingual stargazing site that computes visibility for any place and time. I built the FastAPI back end, three.js front end, API docs, monitoring, and tests; the site renders about 109,000 real stars across 16 orders of magnitude of scale.

  • ANSYS_simulation_IOPresearch code

    Finite-element models of the eyelid and eyeball for a home-use transpalpebral tonometer. During my Shenzhen InnoX Academy internship, I wrote the ANSYS APDL models and scripts that supported the probe-control and calibration work behind three patent applications.

  • ForgeSpec-Studioprototype

    An AI-assisted CAD tool that turns a loose engineering brief into a reviewable assembly specification. I built it to generate deterministic CadQuery source from a standard-parts library and export STEP and STL with a browser preview.

  • ANSYS_skillexperimental

    A validation layer for automated ANSYS Mechanical runs. I built it to record the stage each run reached and the result evidence behind it; a cantilever benchmark matches Euler-Bernoulli theory within 0.223%.

  • CoughKDresearch prototype

    A research pipeline for cough-audio screening. It prepares subject-disjoint data and distils large audio teachers into smaller student models.

Systems and developer tools

  • code-with-piactive experiment

    A terminal broker where an AI coding agent and its user watch or take over the same live shell. I wrote it in C11 over Windows ConPTY and POSIX PTY with authenticated local IPC, and added CI tests on Windows and Linux.

  • Harmony_TaskFlowprototype

    A HarmonyOS systems-integration experiment: a task app with calendar sign-in, a cloud back end and a native proxy core.

  • pixel_probetopsupporting project

    A lightweight multi-server monitor used to watch the research group's GPU servers, with a web UI and an Android viewer.

  • stm32-cli-toolkitsmall tool

    A set of shell wrappers around OpenOCD for building and flashing STM32 projects from a terminal or headless machine.
